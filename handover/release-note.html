Dev release note: static category and price pages

2026-11-22. In-house. Read this first.

Read in this order: this note, the mockups, dev-handover.html (every page, URL, breadcrumb, link and tag on one sheet), content-template.html (copy templates), structured-data-reference.html (schema types and the Idea page reference). Domain: https://www.buildingworld.ai.
Page creation rules (please read first)
  • Category pages (L2 and L3 under Products): create the page only if the category has at least 30 products listed. Otherwise no page is created.
  • Price pages (every price page type): create the page only if at least 30 products have a price shown. Products priced on request do not count. Otherwise no page is created.
  • A page that is not created has no URL, no sitemap entry and no link from any strip. It is created when it reaches the limit.

1. What to build

  • One base template, rendered from data. The product cards are the same on every page. The strip above the cards and the strips after the View All button change by page type.
  • L1 categories stay in the application. There is no static L1 page. L2 and L3 are static pages.
  • Everything that changes per category is a {{token}}. Tick the box at the bottom right of any mockup to see them (purple). Orange blocks are the same on every page.
  • Pages: category pages (L2 and L3), price pages (national, city, brand, brand + city, range, type) and one price hub.

4. The price hub is one page

  • The price hub is one common page at /price/. Pan-India Prices, In My City and Brand Prices are toggle views inside that page, not separate pages or URLs.
  • All three views are in the HTML (JavaScript only hides the ones not selected), so every link is crawlable.
  • The toggle is in the same place: centred under the site header, above the hero. Do not repeat it lower on the page.

5. Breadcrumbs

  1. Start with Home.
  2. Show every level above the page that has its own page. L1 links to the application page; L2 and L3 are static pages.
  3. The last crumb is the page H1 and is not a link. Every other crumb links to a real page.
  4. The visible breadcrumb and the BreadcrumbList schema must match.

9. Publishing rule

  • Build the template for every category. The two page creation rules at the top of this note decide which pages exist.
  • Category pages (L2 and L3 under Products): create the page only if the category has at least 30 products listed. Otherwise no page is created.
  • Price pages (every price page type): create the page only if at least 30 products have a price shown. Products priced on request do not count. Otherwise no page is created.
  • A page that is not created has no URL, no sitemap entry and no link from any strip. It is created when it reaches the limit.
  • Category pages do not target price. Price pages own the price keyword. Each page has its own self-canonical.
  • 24 product cards on category pages, 12 on price pages. Keep each page's HTML under 2 MB.

10. Ideas pages

Ideas L2 pages (live example: /idea/residential/modern-bedroom-designs.html) are in-house. They use a similar template, with larger card images because the audience is image-led. Mockup: Modern Bedroom Designs, built from the live page's real cards and FAQs. Differences from the category template: larger image cards (three across), no price or spec rows, an Explore Idea Categories strip, pagination links, and a Shop the look strip to related product categories (links proposed).
