2026-11-22. Schema types and the Idea page reference.

Use the same schema as the live Idea page. We are not writing the scripts here: follow the types below and use the Idea page as the reference.

Reference

  • Live Idea page: https://www.buildingworld.ai/idea/residential/modern-bedroom-designs.html
  • Saved copy of that page: https://seobiopse.github.io/buildingworld-static-page-mockup/handover/reference/idea-modern-bedroom-designs.html (open the page source and search for application/ld+json)

Schema types per page

PageSchema types
Category, price and hub pagesBreadcrumbList, CollectionPage, ItemList (the links on the page), FAQPage. Organization and WebSite stay sitewide, as on the live site.
Idea pages (live)Organization, WebSite, CollectionPage, CreativeWork, ImageObject, BreadcrumbList, ItemList, FAQPage

Rules

  1. Absolute URLs (https://www.buildingworld.ai/...).
  2. The BreadcrumbList matches the visible breadcrumb: same names, same order, same URLs. The last item is the page itself.
  3. The FAQPage text matches the visible FAQs word for word. Do not mark up FAQs that are not on the page.
  4. The ItemList lists the links on the page (position, name, url). numberOfItems is the real count.
  5. No Product, Offer or AggregateOffer on listing pages. Prices stay in the visible text.
  6. dateModified is the "last updated" date shown on the page.
  7. Validate each page type with Google's Rich Results Test.
