Structured data reference

2026-11-22. JSON-LD examples taken from the mockups.

Use on every page: BreadcrumbList, CollectionPage (with an ItemList of the links on the page) and FAQPage. Put them in one <script type="application/ld+json"> array in the head. Validate each page type with Google's Rich Results Test.

Rules

  1. Absolute URLs everywhere (https://www.buildingworld.ai/...).
  2. The BreadcrumbList matches the visible breadcrumb: same names, same order, same URLs. The last item is the page itself.
  3. The FAQPage text matches the visible FAQs word for word (links removed). Do not mark up FAQs that are not on the page.
  4. dateModified is the "last updated" date shown on the page.
  5. The ItemList lists the links on the page (products, or price pages on the hub): position, name, url. numberOfItems is the real count.
  6. No Product, Offer or AggregateOffer on listing pages. Prices stay in the visible text.
  7. FAQ rich results are shown only for some sites. The markup is still correct and helps search and answer engines.
